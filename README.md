# WhiteSharp

Futureboard Studio's real-time pitch correction as a VST3, CLAP and VST2 plug-in for Windows.

**Download:** get the installer from [Releases](https://github.com/futureboard/whitesharp-release/releases/latest).

More: https://futureboard.studio/plugins/whitesharp

This repository only hosts release builds. WhiteSharp is developed in [Futureboard Studio](https://github.com/futureboard/futureboard-studio).
